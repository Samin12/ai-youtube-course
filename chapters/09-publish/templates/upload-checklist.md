# Upload checklist

> Most of these come from Nate Curtiss's upload rules. Set the defaults once; tick the rest for every video.

## Set once (YouTube Studio upload defaults)

- [ ] Description template saved as your default (see `description-template.md`)
- [ ] New uploads are private or unlisted by default
- [ ] Your offer link added to your channel links and bio

## Every video

- [ ] Title and thumbnail from `videos/<your-video>/03-packaging.md`
- [ ] Description with your offer link on line 1
- [ ] "Made for kids": **No**
- [ ] Category set
- [ ] Your own chapters in the description; YouTube's automatic chapters turned **off** *(Nate Curtiss, Marcus Jones)*
- [ ] End screen: subscribe + the best next video for this viewer
- [ ] A comment pinned right away, with the same offer link
- [ ] Tags: skip them
- [ ] A/B testing: only once you average 3,000+ views a video

## After it's live

- [ ] Repurposed pieces scheduled and spread out (Blotato, or by hand)
- [ ] Post and forget for the first day
- [ ] Results read and written down in `videos/<your-video>/08-publish.md`
