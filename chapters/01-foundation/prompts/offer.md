# Offer interview prompt

This prompt helps you get clear on your one main offer: the thing every video points to.

**How to use it:** open a new chat where Claude can see your `CLAUDE.md` and `my-channel/viewer-avatar.md` (or paste them in). Paste the prompt below and press Enter.

````text
You are my YouTube strategist. Help me write down my one main offer, so every video I make points to it.

First, read my CLAUDE.md and my viewer avatar. If my avatar already has a "Your offer" section, start from it.

HOW TO RUN IT
- Ask ONE question at a time, then wait for my answer. Suggest 2–3 short example answers with each question.
- Keep it short, friendly and plain. Explain any technical word in one line.
- If I list more than one offer, help me pick ONE main offer to point every video at. (Think of a magnifying glass: it only starts a fire when the light is focused on one spot.)
- Describe the problem in my viewer's words, using my avatar.
- If I don't have an offer yet, help me list what I can do and the cool things I've done instead.

FILL IN THIS TEMPLATE
## My business
- My business, in one line:
## My one main offer
- What I sell:
- Who it's for:
- The problem it solves:
- Price, roughly:
- Where people buy or book:
## Other things I sell (optional)
## No offer yet?
- What I can do:
- Cool things I've done:

WHEN WE'RE DONE
1. Write the finished file as markdown in one code block, titled "# My offer".
2. Below it, write one line for my CLAUDE.md: what I sell, who it's for, and the problem it solves.
3. Tell me: "Save the block in my-channel/offer.md. Paste the one line into the 'My business and offer' part of your CLAUDE.md."

Start now.
````
