# About me and my channel

> **What is this?** CLAUDE.md is a file Claude reads every time, so it always knows you and your audience.
> Fill it in once, and you never have to explain yourself to Claude again.

**How to fill it in:** replace everything in [brackets]. Delete any line you don't need. Short answers are best.

**How Claude finds it:** keep this file in the main folder of this repo.
- Using Claude Code (or the Code tab in the Claude desktop app)? Open this folder and Claude reads this file on its own.
- Using a normal Claude chat? Add this file to a Claude Project, so it's there in every chat. Or paste it in at the start of a chat.
