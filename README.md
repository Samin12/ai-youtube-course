## How to use this repo

A "repo" (short for repository) is just a folder of files that lives online. This one holds everything you need for the course.

**1. Get the files.**

- **Easiest:** click the green **Code** button at the top of this page, then **Download ZIP**. Unzip it somewhere you can find it, like your Desktop.
- **If you use Git** (a tool for copying and tracking files): `git clone https://github.com/Samin12/ai-youtube-course.git`

**2. Open your AI tool.**

Any AI tool works. I recommend the **Claude desktop app** with the **Claude Opus** model. That's what I use.

**3. Do the steps in order.**

Start with Step 1. It's required before the rest of the course, because every later step builds on it.

## What's in this folder

- `CLAUDE.md`: your "about me" file for AI. You fill it in during Step 1.
- `steps/`: one folder per step, with instructions.
- `templates/`: blank forms you fill in.
- `prompts/`: copy-and-paste prompts. They work in any AI tool.
- `examples/`: filled-in examples, so you can see what "done" looks like.
- `.claude/skills/`: the same prompts as Claude skills. A skill is a saved set of instructions Claude can run for you. (They work in Claude Code, the version of Claude that can read and save files on your computer.)

**Can't see the `.claude` folder?** Folders that start with a dot are hidden. On a Mac, press **Cmd + Shift + .** in Finder to show them. On Windows, turn on **View > Hidden items** in File Explorer.
