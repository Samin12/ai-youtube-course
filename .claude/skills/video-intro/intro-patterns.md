# Intro patterns (from Samin's top videos)

How Samin's best videos open, word for word from the captions (lightly cleaned), with the 4 P's marked. Use these when the user has no past intros of their own. If they do, copy theirs first.

Every one of them does the same 4 things: **Promise** (the first line says what the title says) → **Proof** → **Plan** (the levels or steps) → **Persona** (who it's for) → "Let's get into it."

## Lines Samin uses in almost every intro

- "In this video, I'm going to be breaking down how you can get started in three levels."
- "Even if you've never [done the scary thing] or have zero technical background, you'll be able to do this, because all we're going to be doing is simply speaking to Claude."
- "By the end of this video, you'll …"
- "Let's get into it."
- Right after: "Okay, before we get into anything, I need to give you some context on why this matters."
